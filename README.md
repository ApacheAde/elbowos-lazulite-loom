# Lazulite Loom

Full-colour Python 3 neon weft-shuttle arcade for [ElbowOS](https://x.com/ElbowOS).

Slide a gold beater across a hanging warp and catch flying coloured shuttles.
Each catch weaves a pick into the growing cloth. Missed shuttles snap the streak.
A / D or arrows steer. R resets.

## Play

```
pip install -r requirements.txt
python3 lazulite_loom.py --play
```

## Record a 9:16 reel

```
python3 lazulite_loom.py --record
```

Writes `LAZULITE_LOOM_ElbowOS.mp4` (1080x1920, 15s, 30fps, h264).
